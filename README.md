# 🛰 Starlink Scanner (Windows & Android)

**Starlink Scanner** یک ابزار تخصصی، مدرن و قدرتمند برای اسکن، آشکارسازی، ردیابی و تخمین موقعیت فیزیکی روترها و ترمینال‌های اینترنت ماهواره‌ای **استارلینک (Starlink / SpaceX)** در محیط اطراف است.

این پروژه شامل **نسخه دسکتاپ ویندوز** (کامپایل‌شده و مستقل) و **پروژه کامل اندروید** (Jetpack Compose + Material 3) به همراه پایپ‌لاین بیلد و انتشار خودکار در GitHub Releases است.

---

## 🌟 ویژگی‌های کلیدی

### ۱. موتور شناسایی و امتیازدهی چندفاکتوره (Scoring Engine)
* **تطابق پیشوندهای OUI:** شناسایی مک‌آدرس‌های مستقیم شرکت SpaceX (`74:24:9F` ،`00:26:12`) و قطعه‌سازان همکار.
* **تحلیل فریم‌های سخت‌افزاری (Vendor IE):** بررسی تگ‌های اختصاصی بیکن.
* **شناسایی استانداردهای وای‌فای ۵ و ۶:** بررسی پشتیبانی از HT / VHT (802.11ac) و HE (802.11ax / WiFi 6).
* **کانال‌های پیش‌فرض:** پایش کانال‌های استاندارد استارلینک (1، 6، 11 روی 2.4GHz و 36، 40، 44، 48 روی 5GHz).
* **خوشه‌بندی فرستنده‌ها (BSSID Cluster):** کشف رادیوهای چندگانه روی یک سخت‌افزار فرستنده مشترک.

### ۲. رادار انیمیشنی و تخمین فاصله فیزیکی (Proximity & Radar)
* رادار گرافیکی با خط اسکن چرخشی ۳۶۰ درجه.
* تخمین فاصله به متر با استفاده از مدل‌های افت مسیر امواج (**Log-Distance Path Loss**).
* تنظیم پروفایل محیطی: فضای باز (Open Space)، فضای داخلی، متراکم با دیوار (Dense) و بین طبقات (Multi-Floor).
* تخمین طبقه و ارتفاع با سنسور فشارسنج (Barometer) در نسخه اندروید.

### ۳. رفع باگ موقعیت مکانی (GPS)
* حل مشکل عدم ذخیره مختصات جغرافیایی به صورت ۳ لایه‌ای:
  1. فراخوانی آنی آخرین موقعیت معتبر کش‌شده (`lastLocation` / 0ms delay).
  2. استفاده از موقعیت‌یابی شبکه‌ای و دکل در محیط‌های بسته (`PRIORITY_BALANCED_POWER_ACCURACY`).
  3. بازگشت به سیستم موقعیت‌یابی پیش‌فرض و امکان ثبت دستی مختصات.
* ثبت خودکار طول و عرض جغرافیایی در پایگاه داده SQLite و دکمه مستقیم **مشاهده روی نقشه (Google Maps)**.

### ۴. هشدار صوتی و خروجی‌گیری
* پخش آلارم صوتی در لحظه شناسایی استارلینک.
* صدور خروجی تاریخچه به فرمت‌های **CSV**، **JSON** و **TXT** با جزئیات کامل و لینک‌های نقشه.

## 💻 راهنمای اجرای نسخه ویندوز

### اجرای مستقیم فایل کامپایل‌شده:
کافی است فایل **`StarlinkScanner.exe`** را در پوشه پروژه دابل‌کلیک کنید یا از فایل **`run.bat`** استفاده نمایید.

### اجرای از طریق سورس پایتون:
```powershell
pip install -r requirements.txt
python main.py
```

---

## 📱 راهنمای پروژه اندروید

پوشه **`android_project`** یک پروژه کامل و آماده باز شدن در **Android Studio** است:
* **زبان:** Kotlin
* **رابط کاربری:** Jetpack Compose + Material 3
* **پایگاه داده:** AndroidX Room Database
* **سرویس پس‌زمینه:** Foreground Service همراه با هشدارهای محلی

برای بیلد APK از طریق ترمینال:
```bash
cd android_project
./gradlew assembleDebug
```

## 🚀 پایپ‌لاین بیلد و انتشار خودکار (GitHub Actions CI/CD)

اکشن طراحی‌شده در مسیر `.github/workflows/release.yml` با ایجاد هر تگ نسخه (مانند `v1.0.0`) یا به صورت دستی (`workflow_dispatch`) به صورت خودکار:
1. نسخه ویندوز را روی سرور `windows-latest` با PyInstaller کامپایل می‌کند (`StarlinkScanner-Windows.exe`).
2. نسخه اندروید را روی سرور `ubuntu-latest` با Gradle بیلد می‌کند (`StarlinkScanner-Android.apk`).
3. یک **GitHub Release** رسمی با نسخه مشخص ایجاد کرده و فایل‌های نصبی را ضمیمه می‌نماید.
